# 纯分类图标选择器设计

## 目标

将图标选择器简化为直接按分类连续展示彩色图标，让用户打开弹窗后只需滚动和点选，不再理解或操作图标来源与搜索功能。

## 界面

- 弹窗头部保留“选择分类图标”或“选择账本图标”、关闭按钮。
- 副标题改为“按分类选择彩色图标”。
- 删除搜索输入框和搜索按钮。
- 删除“常用 / 在线 / Emoji”三个来源标签。
- 删除最近使用、在线搜索结果、网络错误提示和 Emoji 分组。
- 主内容按餐饮、购物、交通、住房、医疗、学习、娱乐、旅行、收入、宠物顺序连续展示。
- 底部保留取消按钮，内容区独立滚动并保持背景锁定。

## 行为与数据

- 点击任意内置图标立即回填并关闭弹窗。
- 所有图标来自已内置的 Fluent Emoji Flat 目录，不需要联网。
- 保存键继续使用 `iconify:fluent-emoji-flat:<name>`，不改变分类、账本、流水或备份结构。
- 旧 Emoji、MDI、Tabler 图标继续在已有数据中显示，但不再作为新选择项提供。
- 保留在线图标服务代码用于历史图标恢复，不在选择器界面暴露在线搜索。

## 测试与验收

- 选择器测试确认搜索框、来源标签和 Emoji 选项不存在。
- 测试 10 个分类分组全部存在，共展示 80–120 个唯一图标。
- 测试断网状态下仍能选择并回填内置图标。
- 手机端检查弹窗无横向溢出、内容可滚动、取消与关闭正常。
