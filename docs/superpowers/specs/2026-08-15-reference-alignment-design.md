# 手机记账页面参考图对齐设计

## 目标

在不改变本地存储、图片、统计和备份逻辑的前提下，将快速记账页与账单页按目录参考图重新排版。验收重点是页面结构、控件比例、间距和视觉层级，而不是继续沿用当前自创首页结构。

## 路由与入口

- `/` 默认展示快速记账页。
- `/bills` 展示参考图中的月账单与年账单。
- `/settings` 保留设置、备份和恢复。
- 快速记账页顶部“总账本”进入 `/bills`；账单页返回按钮回到快速记账页。
- 移除全局底部导航，避免出现参考图中不存在的页面壳层。

## 快速记账页

- 顶部：左侧圆形关闭按钮，右侧胶囊形“总账本”。
- 类型：支出/收入大字号水平切换，选中态使用手绘圈线效果。
- 分类：四列大圆形图标；图标、圆圈和文字比例接近参考图；选中分类使用支出红或收入蓝描边。
- 操作栏：图片入口、备注输入与金额同处一条粗描边输入栏；图片选择后在输入栏上方显示缩略图并支持预览、删除。
- 键盘：四列布局。前三列为数字区；第四列依次为“今天、＋、－、确认”。确认按钮按当前收支类型使用语义色。
- 金额支持数字、小数、加减运算；日期按钮选择业务日期。

## 账单页

- 顶部：返回圆形按钮与月账单/年账单胶囊切换。
- 周期：左右箭头切换月份或年份，文字居中展示。
- 收支：右侧胶囊切换支出/收入。
- 汇总卡：笔数、合计、收入/支出和结余按参考图展示。
- 趋势区：标题、柱状/折线切换与白色趋势卡。
- 分类排行：环形图、图例、排行条和明细列表保持参考图顺序。
- 页面背景、卡片色、粗描边、圆角与语义色统一复用现有 token。

## 保留功能

- IndexedDB 本地持久化。
- 每笔多图片上传、即时预览和全屏查看。
- 新增、编辑、删除账目。
- 月/年统计、分类排行和明细。
- ZIP 导出、导入与 PWA 离线使用。
- 日期展示继续遵循 `YYYY-MM-DD` 与 `YYYY-MM-DD HH:mm:ss` 规范。

## 验收

1. 375px、390px、430px 下无横向溢出。
2. 快速记账页在 844px 高度中完整显示顶部、两行分类、输入栏和四行键盘；小屏允许垂直滚动但不遮挡确认按钮。
3. 默认入口、顶部结构、四列分类和四列键盘与参考图一致。
4. 月/年账单区块顺序与参考图一致，所有统计随账目更新。
5. 现有单元测试、记账流程、图片预览、编辑删除、备份和离线测试继续通过。
