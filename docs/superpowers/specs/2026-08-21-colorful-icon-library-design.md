# 彩色图标库与中文搜索设计

## 目标

将当前单色的 MDI、Tabler 在线图标体验替换为色彩丰富、适合生活记账场景的 Fluent Emoji Flat，同时解决中文日常用语搜索无法命中的问题。

## 图标来源

- 新增在线选择时仅展示 `fluent-emoji-flat`，保证视觉风格统一。
- Fluent Emoji Flat 由 Microsoft 提供，采用 MIT 许可证。
- 已保存的 MDI、Tabler 图标和原有 Emoji 继续渲染，避免破坏历史分类、账本和流水。
- 新选中的在线图标仍使用 `iconify:<prefix>:<name>` 键并缓存 SVG，因此现有 IndexedDB、离线显示和备份结构无需改变。

## 选择器

- 保留“常用 / 在线 / Emoji”三个入口。
- “常用”改为彩色预设，覆盖餐饮、购物、交通、住房、医疗、学习、娱乐、旅行、宠物、工资和礼物等高频记账场景。
- “在线”只显示 Fluent Emoji Flat 搜索结果，不混入单色图标。
- 搜索无结果时显示相近的彩色常用推荐；没有可推荐内容时使用“没有找到相关图标，换个说法试试”，不要求用户输入英文。

## 中文搜索

- 查询先进行去空格、大小写归一化，再匹配中文词典。
- 词典支持日常说法和近义词，并可为一个中文意图提供多个英文关键词。
- 首批覆盖：
  - 吃饭、餐饮、早餐、午餐、晚餐、外卖、火锅、烧烤、奶茶、咖啡；
  - 打车、公交、地铁、开车、加油、停车；
  - 买菜、超市、购物、网购、衣服；
  - 房租、住房、水费、电费、燃气、物业；
  - 医疗、看病、药品、宠物、学习、娱乐、旅行、工资、奖金、礼物。
- 多关键词按顺序搜索后合并去重，限制最终结果数量，避免重复尺寸和肤色变体淹没结果。
- 对 Fluent Emoji Flat 的尺寸、肤色和方向变体进行归并，默认优先基础版本。

## 数据流与错误处理

1. 用户提交中文或英文查询。
2. 查询映射为一组 Fluent Emoji Flat 关键词。
3. 调用 Iconify 搜索接口，限定 `fluent-emoji-flat` 前缀并合并结果。
4. 用户选择后下载 SVG，执行现有安全校验并写入 `iconAssets`。
5. 网络失败时保留本地常用图标和 Emoji，并显示可恢复的网络提示。

## 测试与验收

- 单元测试覆盖“吃饭”“外卖”“地铁”“买菜”等中文查询、多关键词合并去重和基础变体优先。
- 选择器测试验证搜索后切换在线页、仅出现 Fluent Emoji Flat、无结果时出现本地推荐。
- 回归测试验证旧 MDI、Tabler、Emoji 仍可显示，备份导入导出不受影响。
- 手机端验收确认彩色图标清晰、网格无溢出、搜索与选择流程可完成。
