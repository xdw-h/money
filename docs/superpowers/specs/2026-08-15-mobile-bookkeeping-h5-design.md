# 手机 H5 记账应用设计

## 1. 目标

实现一套可在手机浏览器使用并安装到桌面的记账 PWA。页面参考目录中的 9 张截图，保留方格纸背景、黑色手绘线条、米白卡片、蓝色收入和红色支出的视觉语言。所有账目与图片保存在当前手机浏览器本地，不依赖后端。

## 2. 范围

- 首页总览：本月结余、收入/支出摘要、最近账目。
- 快速记账：收入/支出、分类、金额、备注、日期、多图片上传。
- 账单统计：月/年切换、收入/支出切换、柱状图/折线图、分类排行、明细列表。
- 设置：备份导出、备份导入、清空数据、PWA 安装提示。
- 图片凭证：多图上传、手机拍摄、上传即显示、缩略图、全屏预览、左右切换、删除。

不包含账号体系、云端同步、多人共享和服务端图片识别。

## 3. 页面与导航

### 3.1 首页

首页是默认入口。顶部展示当前月份与设置入口；主卡片展示本月结余及收支摘要；下方展示最近账目。底部导航包含首页、账单和设置，中央突出“新增记账”按钮。

### 3.2 快速记账页

采用全屏沉浸式录入：

1. 切换支出或收入。
2. 选择分类。
3. 输入金额、备注和业务日期。
4. 从相册选择多张图片或调用相机拍摄。
5. 图片处理完成后立即显示缩略图。
6. 保存账目，成功后返回首页并刷新统计。

### 3.3 账单页

支持月账单与年账单切换，并支持支出与收入视角切换。内容依次为汇总卡、趋势图、分类排行和明细列表。趋势图可切换柱状图与折线图。

### 3.4 设置页

提供 PWA 安装引导、ZIP 导出、ZIP 导入和清空全部数据。清空数据属于破坏性操作，必须二次确认。

## 4. 视觉规范

- 背景：浅米灰方格纸纹理。
- 卡片：米白色、小阴影、较大圆角，但避免层层嵌套。
- 描边：深色、略粗，模拟手绘工具感。
- 收入：蓝色；支出：珊瑚红；分类图表：暖黄色为主。
- 字体：系统中文字体，金额使用更高字重。
- 适配宽度：375px、390px、430px；内容区设置安全边距，并兼容刘海屏安全区。
- 日期展示：仅日期使用 `YYYY-MM-DD`；包含时间使用 `YYYY-MM-DD HH:mm:ss`；空值使用 `-`；解析失败不得显示 `Invalid Date`。

## 5. 技术架构

- Vue 3 + Vite：页面与构建基础。
- Vue Router：页面路由。
- Pinia：账目、分类、筛选和统计状态。
- IndexedDB：账目、分类、图片二进制与缩略图。
- ECharts：月/年趋势及分类图表。
- Vite PWA：桌面安装、资源缓存和离线启动。
- JSZip：导出和导入包含 JSON 与图片文件的 ZIP 备份。

业务层与 IndexedDB 之间通过独立仓储层通信，页面不直接操作数据库。

## 6. 数据模型

账目记录包含：

- `id`：唯一 ID。
- `type`：`expense` 或 `income`。
- `amount`：以分为单位的整数，避免浮点误差。
- `categoryId`：分类 ID。
- `occurredAt`：业务发生时间，内部使用 ISO 8601。
- `note`：备注。
- `imageIds`：关联图片 ID 数组。
- `createdAt`、`updatedAt`：创建与更新时间。

图片记录包含：

- `id`、`recordId`、`name`、`mimeType`、`size`。
- `blob`：压缩后的可预览图片。
- `thumbnailBlob`：列表缩略图。
- `createdAt`：上传时间。

## 7. 图片处理流程

选图或拍照后先校验 MIME 类型与文件大小，再在浏览器端按合理分辨率压缩并生成缩略图。处理完成的图片进入待保存区并立即展示；用户可点开预览或移除。保存账目时，账目与图片在同一业务事务中落库。任何图片写入失败都不会产生引用缺失的半条账目。

图片全屏预览支持左右滑动、序号提示、关闭和删除。删除已保存图片时同步更新账目中的 `imageIds`。

## 8. 备份与恢复

导出 ZIP 包含：

- `manifest.json`：备份版本、生成时间和文件统计。
- `records.json`：账目与分类数据。
- `images/`：图片文件。

导入时先完整校验清单、JSON 结构和图片引用，再写入 IndexedDB。相同 ID 的账目默认跳过并给出数量汇总。格式错误、版本不兼容或图片缺失时终止导入，不覆盖现有数据。

## 9. 异常与空状态

- 存储空间不足：提示释放空间或先导出备份，并保留未提交表单。
- 图片格式不支持或损坏：标记具体文件并允许移除后继续。
- 备份导入失败：显示失败原因，不改变当前数据。
- 无账目：展示新增第一笔账目的操作入口。
- 图表无数据：展示空态，不绘制误导性的零值趋势。

## 10. 验收标准

1. 可新增、编辑、删除收入与支出，刷新或重新打开后数据仍存在。
2. 每笔账目可上传多张图片，上传后立即显示，并支持全屏预览、左右切换和删除。
3. 月/年账单的汇总金额、趋势、分类排行和明细随数据同步更新。
4. ZIP 能完整导出并恢复账目与图片，错误备份不会覆盖现有数据。
5. 支持安装到手机桌面并离线启动已缓存的应用壳与本地数据。
6. 在 375px、390px、430px 宽度下无横向溢出，主要操作可触达。
7. 日期展示覆盖 ISO 时间、带毫秒/时区时间、普通数据库时间、空值与解析失败场景。

## 11. 测试重点

- 账目金额计算与月/年聚合。
- 日期格式化及业务时区转换。
- IndexedDB 仓储的新增、更新、删除和事务回滚。
- 多图片上传、压缩、预览、删除及空间不足。
- ZIP 导出/导入、重复记录、损坏文件和版本不兼容。
- PWA 安装、离线重开和缓存升级。
- 三种目标手机宽度的响应式页面验证。
