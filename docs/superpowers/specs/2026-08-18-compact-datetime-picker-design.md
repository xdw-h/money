# 紧凑记账时间选择器设计

## 目标

将记账页面现有的日期时间选择器改为紧凑布局。日期日历保持可见，小时和分钟不再以大量按钮同时铺开；用户点击时间行后再显示双列滚轮。

## 交互

1. 打开弹窗时显示月份导航、月历、时间行以及底部操作按钮。
2. 时间行显示当前暂存时间，格式为 `HH:mm`。
3. 点击时间行后，在日历区域上方显示小时和分钟双列滚轮；每列只露出约五项，选中项位于中间并使用当前主题色强调。
4. 滚轮选择后更新暂存时间，点击滚轮外部或再次点击时间行可收起滚轮。
5. 点击“取消”关闭弹窗，不提交任何修改。
6. 点击“确定”一次提交完整值，格式保持 `YYYY-MM-DDTHH:mm`。

## 布局

- 弹窗继续使用底部面板形式，宽度和颜色沿用现有主题变量。
- 顶部不再展示独立关闭按钮和重复的完整日期时间；月份导航承担主要标题区域。
- 日历下方是一行“时间”和当前时间按钮。
- 底部使用等宽“取消”“确定”按钮。
- 时间滚轮为面板内浮层，不增加面板高度，不触发页面纵向滚动。
- 在窄屏和低高度设备上，月历单元格允许压缩，但按钮触控区域保持可用。

## 状态与边界

- 日期、小时、分钟均使用弹窗内部暂存状态，只有确认时向父组件发送 `select`。
- 小时范围为 `00` 至 `23`，分钟范围为 `00` 至 `59`，精度为1分钟。
- 切换月份不改变已选时间；选择日期不自动关闭弹窗。
- 不使用原生 `date`、`time`、`datetime-local` 或 `select` 控件。
- 初始值解析失败时沿用组件现有安全兜底，不向页面输出 `Invalid Date`。

## 实现边界

- 主要修改 `DateTimePickerSheet.vue`。
- `RecordEditor.vue` 的调用方式和保存数据格式保持不变。
- 不修改账期日期选择器、月份选择器和账单统计逻辑。

## 验收标准

- 默认状态下不显示24个小时按钮和60个分钟按钮组成的长列表。
- 点击时间行才显示双列滚轮，选择任意分钟后可正确提交。
- 取消不产生 `select` 事件，确定只产生一次 `select` 事件。
- 现有记账编辑回填继续正确。
- 360px宽及常见iPhone高度下无横向或页面纵向溢出。
- 单元测试、类型检查和生产构建通过。
