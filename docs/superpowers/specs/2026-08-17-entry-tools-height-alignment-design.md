# 记账辅助栏高度对齐设计

## 目标

仅调整快速记账页中“添加备注、记账时间、照片”三块的视觉高度，使其上下边缘对齐；不改变现有宽度比例、文字、功能或交互。

## 方案

三块统一使用 `38px` 高度和 `10px` 圆角。备注按钮与时间选择器保留当前样式；照片上传组件的外层、预览容器、上传按钮和图片缩略图统一继承同一高度，并在网格中垂直居中。

不采用三块等宽方案，因为时间内容需要更宽空间；不采用增加外层高度方案，因为会挤压下方金额与键盘区域。

## 验收

- 三块顶部和底部边缘在同一水平线上。
- 时间选择器不再显得高于备注和照片按钮。
- 已上传图片缩略图与上传按钮保持相同尺寸。
- 不改变备注、时间选择和照片上传行为。
