# 底部导航面板高还原设计

## 目标

以用户提供的合格图为唯一视觉基准，完整还原移动端底部导航面板。保留现有五个入口、路由地址、可访问名称和页面隐藏规则，不改变业务行为。

## 视觉结构

- 面板固定在视口底部，主体为半透明白色圆角矩形，带浅紫描边、柔和紫色投影和背景模糊。
- 主体顶部中央形成连续、对称的半圆拱形轮廓，轮廓与面板连接处平滑过渡，不使用独立矩形或生硬遮挡模拟。
- 新增按钮居中悬浮于拱形内，使用紫色渐变圆形、白色粗圆环、外层柔光和白色加号。
- 首页、账单、时间轴、设置均使用统一笔画、圆角端点的线框 SVG 图标，不继续使用字体符号。
- 激活导航项的图标和文字显示为紫色，并在文字下方显示紫色短圆角指示条；非激活项使用灰紫色。

## 响应式规则

- 以 `430px` 内容宽度为桌面开发基准，面板内部尺寸随可用宽度收敛，保持五列等宽。
- 以合格图等比缩放到 `430px` 宽：面板主体高度约 `61px`，中央按钮直径约 `66px`，中央拱形宽约 `104px`。
- 在窄屏上优先保证图标、文字和中央按钮不重叠；保留安全区底部内边距。
- 页面内容底部留白同步增加，最后一项内容不会被新版面板遮挡。

## 组件边界

- `App.vue` 继续负责路由导航结构；四个普通入口内部增加图标 SVG，中央入口保持“新增记账”的可访问名称。
- `App.vue` 内使用一条连续 SVG 路径绘制整个面板外框，使左右顶边、中央拱形和主体边框共用同一条描边；不以两个带边框的独立图形叠加。
- `base.css` 负责布局、状态、阴影和响应式尺寸。
- `tokens.css` 增加底部导航所需的紫色视觉变量，避免把颜色散落在选择器中。

## 行为与异常

- 路由跳转、当前路由激活状态及 `hideNav` 行为保持不变。
- 导航激活色、按钮渐变、描边与阴影由现有主题的 `--primary`、`--border`、`--muted` 动态生成，不保留固定紫色导航变量。
- 支持键盘焦点可见状态；开启减少动态效果时不添加过渡动画。
- 不使用外部图标服务或网络图片，离线 PWA 中视觉保持完整。

## 验收标准

1. 在 `390px` 与 `430px` 视口下，整体轮廓、中央拱形、悬浮按钮和五列关系与合格图一致；拱形肩部连续平滑，无双线、接缝或折角。
2. 四个导航图标均为一致风格的线框图标，激活项具有紫色文字、图标和短下划线。
3. 新增按钮点击区域和“新增记账”无障碍名称保留，所有原路由可正常访问。
4. 页面无横向滚动，底部内容不被面板遮挡，iOS 安全区有效。
5. 构建、现有单元测试和移动布局端到端测试通过。
