# 账期日期保存 DataCloneError 修复设计

## 问题

账期日历能够正确选择日期，但确认后日期回退，页面显示 `DataCloneError`。根因是 `ledgerItems` 中的账本对象被 Vue 转为响应式代理，保存函数通过浅拷贝继续携带嵌套代理对象，IndexedDB 无法克隆该对象。

## 方案比较

- 采用：在账本存储层统一创建纯数据快照，显式复制账本字段及账期起止日期映射，再写入 IndexedDB。边界清晰，并覆盖所有账本更新入口。
- 不采用：仅在设置页面调用 `toRaw`。这会把存储兼容责任放到 UI，其他调用方仍可能复现问题。
- 不采用：序列化为 JSON 再反序列化。虽然可去除代理，但会掩盖非法字段并增加无意义转换。

## 行为

默认账期日期、单月起始日、单月终止日及恢复默认均通过普通账本对象写入。保存成功后界面立即显示新日期；保存失败时保留原数据并显示错误。

## 测试

使用 Vue 响应式账本对象调用真实账本存储函数，覆盖起始日、终止日和默认日期更新，断言 IndexedDB 写入成功且重新读取的数据正确。浏览器中再次选择 `2026-08-13`，确认后不得回退或出现 `DataCloneError`。
